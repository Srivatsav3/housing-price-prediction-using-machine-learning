# A Data-Driven Approach to Housing Price Prediction Using Machine Learning Algorithms

## Project Overview
This project explores the use of machine learning algorithms to predict housing prices in the UK using housing transaction data. It focuses on analysing property-related information, identifying important features and evaluating different predictive models.

## Objectives
- Explore and understand UK housing transaction data.
- Perform data preprocessing and exploratory data analysis.
- Apply feature engineering techniques to prepare the data for modelling.
- Develop and compare machine learning models for housing price prediction.
- Evaluate model performance using appropriate statistical metrics.
- Interpret model predictions using explainable AI techniques.

## Technologies and Tools
- Python
- Machine Learning
- Pandas and NumPy
- Scikit-learn
- SHAP
- LIME
- Data Visualisation

## Machine Learning Algorithms
- Linear Regression
- Random Forest
- Gradient Boosting

## Model Evaluation
Model performance was evaluated using:
- R-squared (R²)
- Root Mean Squared Error (RMSE)
- Mean Absolute Error (MAE)

SHAP and LIME were also used to support the interpretation of model predictions.

## Key Learning Outcomes
- Practical experience in data preprocessing and exploratory data analysis.
- Understanding of machine learning model development and evaluation.
- Experience comparing predictive algorithms.
- Understanding of model interpretability and explainable AI.

## Project Type
MSc Dissertation – University of Essex
